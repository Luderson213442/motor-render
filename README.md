# motor-render

Motor de processamento de vídeo vertical (1080x1920). Cada execução recebe só o id de uma tarefa, baixa a entrada de um armazenamento privado, processa e devolve a saída para lá.

Nada fica guardado aqui: sem releases, artifacts ou cache. A máquina é descartada no fim e a execução é apagada logo depois.
